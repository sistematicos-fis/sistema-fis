# Documentación

Aquí van los documentos del proyecto en Word (`.docx`) o LibreOffice (`.odt`):

- `PMP/`: plan de gestión del proyecto.
- `SRS/`: especificación de requisitos, con los 25 casos de uso.
- `SDD/`: descripción del diseño (arquitectura, clases, secuencias y base de datos).

Los diagramas se hacen en Lucidchart y se exportan como imagen para pegarlos en los documentos.
