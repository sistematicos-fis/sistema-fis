# Documentación del Proyecto - Concesionario Integrado

Este directorio alberga los documentos formales del proyecto de acuerdo con las **Normas y Restricciones del Curso (FIS - Pontificia Universidad Javeriana)**:

### Restricciones Críticas de Formato:
1. **Formato Obligatorio**: Todos los documentos oficiales (PMP, SRS, SDD, PTP e Informes Gerenciales) deben redactarse y entregarse en **MS Word (`.docx`)** o **LibreOffice (`.odt`)**.
   - *Queda estrictamente prohibido entregar documentos en LaTeX, Markdown o PDF.*
2. **Diagramas UML**: Deben ser elaborados exclusivamente con herramientas de edición visual (Enterprise Architect, draw.io, Lucidchart). *Prohibido el uso de herramientas de texto como PlantUML o Mermaid para entregas formales.*
3. **Estructura de Carpetas**:
   - `docs/PMP/`: Project Management Plan (Plan de Gestión del Proyecto).
   - `docs/SRS/`: Software Requirements Specification (Especificación de Requisitos de Software con los 35 Casos de Uso).
   - `docs/SDD/`: Software Design Description (Descripción del Diseño de Software, Arquitectura y Diagramas de Clases/Secuencia).
